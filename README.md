# superstore_sales_analysis

## Project Overview
This project analyzes Superstore sales data using Microsoft Excel. The dataset was cleaned, formatted, and analyzed using PivotTables, charts, KPIs, and interactive dashboard elements.

The goal of this project was to derive business insights related to sales performance, regional trends, and product categories through data visualization and dashboard creation.

---

## Tools Used
- Microsoft Excel
- PivotTables
- Charts
- Slicers

---

## Project Workflow

### 1. Data Cleaning
- Checked for duplicate records
- Verified missing values
- Organized and structured raw data

### 2. Data Formatting
- Formatted columns such as dates and sales values
- Improved dataset readability and consistency

### 3. Data Analysis using PivotTables
Used PivotTables to analyze:
- Monthly sales trends
- regional sales
- sub categorical revenue
- top 5 state wise sub categorical collection shares 

### 4. Data Visualization
Created multiple visualizations including:
- Bar Charts
- Pie Charts
- Line Charts

### 5. KPI Metrics
Created KPI cards for:
- Total Sales
- Average Sales
- Total Orders

### 6. Interactive Dashboard
Built an interactive Excel dashboard using:
- Slicers
- Pivot Charts
- KPI Cards

The dashboard allows dynamic filtering and easier business analysis.

---

## Features
- Interactive dashboard
- Dynamic filtering using slicers
- Visual sales analysis
- KPI tracking
- Trend analysis
